# Sesion 7: UX, Logros y Diseño Interactivo

## 1. UX (Experiencia de Usuario)
Es cómo se **siente** el usuario al usar un producto: fácil, útil y sin fricción.

- **Claves:** usabilidad, accesibilidad, consistencia, feedback.
- **Proceso:** investigar → diseñar → prototipar → testear → iterar.
- UX ≠ UI: UX es la experiencia completa; UI es solo lo visual.

## 2. Diseño de Logros
Sistema de **recompensas y metas** que motiva al usuario a seguir usando el producto.

- **Tipos:** progreso, habilidad, sociales, sorpresa, colección.
- **Basado en:** refuerzo positivo, progreso visible, estatus.
- **Buenas prácticas:** alcanzables, con sentido, con feedback claro, no obligatorios.
- **Errores:** logros triviales, imposibles, o que premian conductas dañinas.

## 3. Diseño Interactivo
Define **cómo responde** el producto a las acciones del usuario.

- **Elementos:** estados (hover, loading, error), transiciones, microinteracciones, flujos.
- **Principios (Nielsen):** visibilidad del estado, control y libertad, prevención de errores, feedback claro.
- **Microinteracciones:** disparador → regla → feedback → bucle.

## Relación entre los tres
- **Diseño interactivo** = *cómo* funciona.
- **Logros** = *por qué* el usuario vuelve.
- **UX** = *resultado global* de ambos.

> Un buen producto se ve bien, responde bien y motiva a volver.
